# @promotor/api

API NestJS do sistema operacional de promotores.

Use o README raiz em `../../README.md` como documentacao principal de setup, banco, auth, execucao e validacao.

Scripts mais usados neste workspace:

- `npm run start -w @promotor/api`
- `npm run start:dev -w @promotor/api`
- `npm run prisma:generate -w @promotor/api`
- `npm run prisma:migrate -w @promotor/api`
- `npm run prisma:deploy -w @promotor/api`
- `npm run prisma:seed -w @promotor/api`
- `npm run validate:runtime -w @promotor/api`
- `npm run validate:auth:runtime -w @promotor/api`
